# Security Policy

## Supported versions

| Version | Supported |
|---|---|
| 0.1.x | yes |

## Reporting a vulnerability

Please **do not** open a public issue for security problems.

Email the maintainers with:

- description of the issue
- steps to reproduce
- impact assessment if known

We aim to acknowledge reports within 7 days and publish fixes as quickly as practical.

## Scope notes

JMK executes `git` and reads repository files locally or in CI. Treat untrusted repositories with the same caution you would give any code-analysis tool.
